# Bhagavat Powertech (P) Ltd - Rooftop Quotation Engine

A fast, responsive, single-page quotation generation tool built for Bhagavat Powertech solar EPC workflows.

## Features
- **Strict Single-Page PDF Layout:** Fits standard A4 boundaries precisely with no page runoffs.
- **Dynamic Brand & Series Matrix:** Supports Waaree, Tata, Adani, V-Guard, Luminous, UTL, Genus, Amaze, V-Sole, and Power One.
- **Automatic TOPCon Detection:** Wattages $\ge 600\text{ Wp}$ (600, 610, 615, 620) automatically flag as TOPCon.
- **Statutory DISCOM & Subsidy Workflow:** Formatted for TPCODL net metering and PM Surya Ghar: Muft Bijli Yojana rules.
- **Stage Payment Breakdown:** 70% advance, 20% on delivery/installation, 10% on DISCOM meter installation & handover.

## Quick Setup
1. Push all files to the `main` branch of your GitHub repository.
2. In GitHub, open **Settings** > **Pages** > **Branch: main / root** and click **Save**.
3. Place `stamp.jpg` inside the `assets/` folder.
